
# Contributor Code of Conduct

## Our Pledge
We pledge to make participation in our project a welcoming and harassment-free experience for everyone.

## Our Standards
We encourage kindness, respect, constructive feedback, and professional communication. Harassment, discrimination, insults, and personal attacks are unacceptable.

## Enforcement Responsibilities
Project maintainers are responsible for clarifying and enforcing acceptable behavior and taking appropriate corrective action.

## Scope
This Code of Conduct applies to all project spaces, including GitHub issues, pull requests, discussions, and public representation of the project.

## Enforcement
Instances of unacceptable behavior may be reported privately to the project maintainers through GitHub. Reports will be reviewed fairly and confidentially where possible.

## Enforcement Guidelines
Project maintainers will follow these guidelines:
1. Correction: A private warning for minor inappropriate behavior.
2. Warning: A formal warning for repeated or more serious behavior.
3. Temporary Ban: Temporary suspension from project participation.
4. Permanent Ban: Permanent removal for severe or repeated violations.
