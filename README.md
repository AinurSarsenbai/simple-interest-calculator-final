
# Simple Interest Calculator

This project is a simple interest calculator developed using Bash scripting.

## Description

The calculator computes simple interest based on three user inputs:
- Principal amount
- Annual rate of interest
- Time period in years

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Features

- Accepts user input
- Calculates simple interest
- Displays the calculated interest
- Easy to use through the command line

## How to Run

```bash
bash simple-interest.sh
```
